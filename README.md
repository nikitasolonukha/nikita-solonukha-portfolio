# Никита Солонуха — портфолио

Публичный статический экспорт портфолио: 35 канонических кейсов с desktop/mobile-материалами и документированными границами доказательств. GitHub Pages открывает новый сайт через корневой `index.html`.

- `site/` — финальный личный сайт: Home, Work, About, Archive и 35 кейсов;
- `portfolio/` — сохранённая предыдущая версия и канонические данные;
- `review/` — полный визуальный каталог и страницы кейсов;
- `projects/` — screenshots, walkthrough и `case.md` для каждого опубликованного пакета.
- `references/` — изученные референсы и принципы композиции; `site/QA_REPORT.md` — результаты проверок.

Архивные обложки явно отделены от настоящего UI. Credentials, исходные приватные workflow и персональные данные в экспорт не входят.
