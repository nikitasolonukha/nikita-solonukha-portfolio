# Никита Солонуха — портфолио

Публичный статический экспорт портфолио: 35 канонических кейсов с desktop/mobile-материалами и документированными границами доказательств. GitHub Pages открывает основной интерфейс через корневой `index.html`.

- `portfolio/` — основной публичный интерфейс;
- `review/` — полный визуальный каталог и страницы кейсов;
- `projects/` — screenshots, walkthrough и `case.md` для каждого опубликованного пакета.

Архивные обложки явно отделены от настоящего UI. Credentials, исходные приватные workflow и персональные данные в экспорт не входят.
