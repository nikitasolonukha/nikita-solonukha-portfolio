# Новый сайт портфолио — локальная версия

Открыть: http://127.0.0.1:4312/portfolio/

Главная, пять выбранных работ, каталог 41 самостоятельного пакета с поиском и категориями, страницы кейсов, 87 видеозаписей, дополнительные экраны и фактическое исследование. Исходная галерея материалов остаётся в ../review/.

Сайт использует локальные JSON/HTML/CSS/JS и существующие ассеты; внешних CDN, runtime-сервисов и форм отправки нет. Контакт @solonflowai взят из старого публичного портфолио. Изображения первого экрана и каталога переведены в WebP: 7.85 MB → 2.12 MB суммарно для 41 файла; нижние изображения загружаются лениво.

Проверка: главная на 390/768/1440; переключение hero, 41 проект, категории, поиск, пустое состояние, переход к кейсу, раскрытие исследования, clipboard. Все 41 страницы кейсов проверены на мобильной ширине: загрузка видео, корректные пропорции, отсутствие overflow и ошибок JS. Неизвестный project получает понятный экран с возвратом. Результаты — QA.json.

Публикация не выполнялась. noindex установлен для локального просмотра, но не является защитой доступа. В каталоге есть приватные источники и реконструкции: публичный выпуск требует проверки ограничений из case.md. Настоящие UI не перерисованы, исходные продукты не изменялись.
