# Product visual audit

Сверено с `PROJECT_PATHS.md` (35 canonical cases). Это **новый** статус визуальной доработки самих продуктов, отдельно от ранее опубликованного статуса портфолио-кейсов. `READY` здесь ставится только после QA 1440/768/390, новых кадров и walkthrough. Исходный продукт и demo polish различаются в `case.md`.

Приоритет: Shopify → KONTUR → MAGNUM → Портной → Meta Ads → Пифпаф → GARMONY → AI Support; далее остальные по запросу.

Финальная техническая сверка этого прохода: 35/35 canonical строк имеют конечный статус (28 READY, 6 BLOCKED, 1 PRIVATE/NDA). Проверено 656 локальных ссылок в `portfolio/data.json` и `review/*.html`: отсутствующих файлов 0. Пять обновлённых review-страниц проверены в **публичном локальном пакете** на 1440/390: ошибок страницы, горизонтального overflow, битых изображений и несовпадений MIME видео 0 (`site/qa/redesign-review-qa.json`). Основная страница портфолио проверена с новыми обложками на тех же ширинах; ленивые изображения вне видимой области не считались битым файлом. Перезаписанные master-видео декодируются браузером: Пифпаф 45 с, Портной 100/74 с, Meta Ads 33 с, KONTUR 28 с на desktop. Блокировки и границы доказательств ниже не скрыты.
