# PP BOT — просмотр рецептов

**Статус: READY (локальный пакет).** Локальная презентация.

Компактный WebApp для чтения рецепта, открытого по ссылке из Telegram: название, КБЖУ, ингредиенты, последовательность приготовления и персональная маркировка просмотра.

## ORIGINAL

[Репозиторий ppbot](https://github.com/nikitasolonukha/ppbot), commit 379b7a958e6981798ae6d1c7a6fd09dbf08b7b82. Два исходных файла: HTML Canvas reader и JSON с 125 рецептами. Данные выбираются по query id. Код использует Telegram WebApp SDK для идентификатора просмотра, watermark и скрытие содержимого при потере видимости. Backend бота, подписки и оплаты в репозитории отсутствуют; не заявляются как проверенные.

## VERIFIED

Воспроизведена ошибка исходника: после рисования меняется canvas.height, что стирает всё изображение. На синтетическом примере получено 0 непрозрачных пикселей из 279 300. После исправления Canvas содержит текст на 390/768/1440, оба рецепта открываются, навигация прокручивает к разделам, отсутствующий id показывает ошибку с восстановлением. Проверено изменение ширины, горизонтального переполнения нет. Результаты в qa.json.

Пользователь передал отдельный реальный визуальный материал Telegram-бота: приветствие, меню приёмов пищи, категории, фильтры и карточки рецептов. Фон исходного коллажа удалён, сами Telegram-экраны не перерисовывались. Эти материалы теперь открывают master walkthrough, после чего видео переходит к проверенной WebApp.

## PORTFOLIO POLISH

Отдельная локальная версия: спокойный оливковый фон и бумажная поверхность, редакционная типографика, ингредиенты и шаги в двух колонках на большом экране и последовательно на телефоне. Renderer сначала измеряет текст, затем задаёт размер canvas и рисует — без очистки результата. Учитывается DPR. Добавлены доступные названия Canvas, клавиатурный фокус и переходы к разделам. Убраны мешающие отладке перехваты console и anti-devtools.

Референсы структуры чтения: [Paprika](https://www.paprikaapp.com/), [Samsung Food](https://samsungfood.com/), [BBC Good Food](https://www.bbcgoodfood.com/recipes). Изображения, рецепты и код не копировались. Таймеры, списки покупок и другие отсутствующие функции не добавлялись.

## DEMO / MOCK

Два специально написанных примера вместо оригинальной коллекции. Профиль demo_reader вымышленный; КБЖУ — условные согласованные числа для интерфейса, не расчёт пищевой ценности. Telegram SDK не вызывает сеть. Переключение между двумя примерами — навигация презентации, не доказательство существования каталога внутри бота.

## Материалы

В публичном кейсе оставлены только переданные Telegram-материалы: меню, фильтры и карточка рецепта. По просьбе владельца демонстрационная WebApp-страница с овсяной кашей убрана из обложки, галереи и публичных видео. Локальные записи WebApp сохранены в архиве проекта как проверочный материал, но в презентации не используются.

Финальные desktop/mobile записи просмотрены по декодированным кадрам. Кейс проверен на 320/390/768/1440: нет переполнения, размеры видео стабильны, постеры совпадают по пропорциям.
