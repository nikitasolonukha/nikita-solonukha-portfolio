# PP BOT · master walkthrough

Записывается реальный локальный Canvas reader, без Telegram backend и без оригинальных рецептов.

00:00 — реальный Telegram: приветствие, меню и выбор приёма пищи.
00:04 — реальный Telegram: категории и фильтры.
00:08 — реальный результат: карточка рецепта с КБЖУ.
00:12 — WebApp: название и состав макронутриентов (условные demo значения).
00:17 — переход к ингредиентам, чтение состава.
00:22 — переход к приготовлению, последовательность шагов.
00:28 — личный просмотр и демонстрационная маркировка.
00:32 — другой пример: тост с томатами.
00:37 — его ингредиенты и шаги.
00:43 — возврат к началу рецепта.

Первые три сцены — монтаж из присланных пользователем реальных Telegram-материалов, а не повторно запущенный бот. Затем идёт запись работающей локальной WebApp. Карта состояний: Telegram → выбор → рецепт; URL id → загрузка JSON → Canvas; навигация → прокрутка к измеренной позиции; смена id → другой рецепт; отсутствующий id → понятная ошибка → открытие доступного примера. Ошибка проверяется отдельно от master. Mobile 390×844, desktop 1440×900.
