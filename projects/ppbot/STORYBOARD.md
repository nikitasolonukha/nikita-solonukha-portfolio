# PP BOT · master walkthrough

Записывается реальный локальный Canvas reader, без Telegram backend и без оригинальных рецептов.

00:00 — открытие рецепта: название, состав макронутриентов (условные demo значения).
00:05 — переход к ингредиентам, чтение состава.
00:10 — переход к приготовлению, последовательность шагов.
00:16 — личный просмотр и демонстрационная маркировка.
00:20 — другой пример: тост с томатами.
00:25 — его ингредиенты и шаги.
00:31 — возврат к началу рецепта.

Карта состояний: URL id → загрузка JSON → Canvas; навигация → прокрутка к измеренной позиции; смена id → другой рецепт; отсутствующий id → понятная ошибка → открытие доступного примера. Ошибка проверяется отдельно от master. Mobile 390×844, desktop 1440×900.
