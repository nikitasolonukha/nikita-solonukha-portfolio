# Women Strange — master

Реальная запись браузера, без изменения скорости. Время каждого экрана фиксируется в master-qa.json; мобильная версия длиннее из-за вертикального расположения моделей.

1. Заставка → первый экран → название и две возможности связаться.
2. Мобильное меню → Escape → повторное открытие → «О бренде».
3. История и детали бренда.
4. Все пять моделей → наведение/фокус → «Уточнить наличие». Внешний переход не выполняется.
5. Этапы заказа → индивидуальный контакт, без корзины и оплаты.
6. Доставка → контакты. Контактные данные скрыты в записи.

Отдельный QA: статические 404/500, возврат на главную, отсутствие overflow на 390/768/1440. Ошибка 500 — шаблон страницы, не реальный отказ backend.
