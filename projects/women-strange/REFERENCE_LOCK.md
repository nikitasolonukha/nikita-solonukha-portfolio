# Reference lock — Women Strange

REFERENCE CASES: Dennis Snellenberg / FABRIC и The Damai.

REFERENCE LIVE SITES: https://fabric-london.com/ и https://thedamai.codebydennis.com/ (при недоступности текущего FABRIC использован сохранённый live capture).

WHY THIS REFERENCE: FABRIC задаёт media-first логику, где образ и ритм кадров важнее интерфейсных контейнеров. The Damai добавляет спокойные паузы и доверие к фотографии. Брендинг референсов не переносится.

REFERENCE SECTION MAP:

- MY HERO ← image-over-type: фактический storefront становится fashion object.
- MY STATEMENT ← type-only пауза фиксирует приоритет изделия.
- MY MASTER ← полноширинный реальный walkthrough.
- MY GALLERY ← асимметричная последовательность экранов вместо product-card grid.
- MY MOBILE ← один крупный вертикальный объект на контрастной поверхности.
- MY INTERACTION ← mobile menu и проявление ссылки модели при hover/focus.

Внутренние captures хранятся в `references/live/fabric/` и `references/live/the-damai/` и не публикуются как работа Никиты.
