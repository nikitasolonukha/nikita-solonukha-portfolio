# Content Factory Marek — сбор контента, темы и конкуренты

**READY — изолированная локальная версия, не production-сервис.**

## ORIGINAL
Источник: Desktop/РАБОТА/Сервисы/Контент-завод/content-zavod Marek. Это отдельный проект от Python ContentFactoryBot. Изучены Next.js admin-dashboard, NestJS content-parser (controller, competitors/trends services), account-management, uniquifier-bot и инфраструктурные описания. 81 исходный файл перечислен с SHA в source-manifest.json. README описывает более широкую систему, чем удалось подтвердить исполнением.

Frontend содержит реальные страницы parser/trends/competitors и обработчики React. В parser есть запуск и polling API, история статусов и счётчик публикаций. Trends и competitors изначально используют локальные массивы useState: фильтр по платформе, добавление хештега/профиля, переключение tracking. Это не доказательство живого мониторинга. При уходе со страницы изменения теряются по исходной модели состояния.

Продукт предназначен редакции, которая собирает источники и сравнивает темы/профили. Личный вклад Никиты, состав команды и право публично показывать этот источник отдельно не подтверждены. Метрики результата и число пользователей не заявляются.

## VERIFIED
Сборка Next и TypeScript проходят. В исходнике отсутствовал PostCSS config: успешная сборка оставляла необработанные @tailwind. В отдельной копии восстановлен config и выполнена чистая сборка. Исходные файлы не изменены.

12 offline проверок оригинальных TypeScript-классов с внедрёнными заглушками зависимостей: engagement при нулевой аудитории, расчёт доли, средние метрики, темы, фильтрация/ранжирование популярных публикаций, агрегирование двух платформ, hashtags, keywords и пустой набор. Это модульные проверки отдельных классов, не запуск полного Nest/DB/очередей. Две проверки фиксируют существующие дефекты: Cyrillic теряется в regex keywords; controller вызывает отсутствующий discoverTrends. Engagement backend возвращает долю, а seed frontend показывает проценты — сквозное соответствие не доказано.

UI QA на 390/768/1440: пустой ввод disabled, parser success с 3 подготовленными результатами, локальная ошибка parser, четыре platform filters, добавление hashtag/profile, stop/resume tracking, раскрытие ограничений, отсутствие JS errors и горизонтального overflow. Подробности ui-qa.json. Таблицы на планшете имеют собственную горизонтальную прокрутку; на телефоне превращаются в подписанные строки.

## PORTFOLIO POLISH
Новая тёмная оболочка с четырьмя разделами, обзор с назначением каждого инструмента, типографика, плотность, формы, focus, адаптивные таблицы. Удалены неработающие кнопки аналитики/подробностей и ссылки на несуществующие страницы. Сохранены исходные обработчики рабочих разделов. Новый обзор и визуальная система не выдаются за исторический дизайн.

Референсы категории: [Buffer Insights](https://buffer.com/insights) — обзор по каналам и понятные определения метрик; [Sprout Social](https://sproutsocial.com/features/social-media-analytics/) — аналитика социальных платформ; [ContentStudio](https://contentstudio.io/) — рабочее пространство редакции. Использован принцип разделения задач и сводки, чужие блоки/изображения/тексты не копировались.

## Не подтверждено / PLANNED
Production auth, accounts, PostgreSQL/Redis/Kafka/Vault, реальные социальные платформы, AI-уникализация, Telegram, публикация и полный end-to-end pipeline не запускались. Версия Next 14.0.0 сохранена для воспроизведения локального источника; этот demo нельзя считать готовым к публичному deployment без обновления зависимостей и отдельного security review. Найденный hardcoded credential не переносился в demo и не использовался; владельцу оставлен вопрос о ротации.
