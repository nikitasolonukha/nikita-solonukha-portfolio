# Рынок — интерактивная учебная модель

**Статус: READY (локальный пакет).** Небольшой кейс по визуализации данных.

Учебная модель спроса и предложения на примере электромобилей: сравнить исходное и новое равновесие, прочитать координаты, скрыть кривую и рассмотреть участок графика.

## ORIGINAL

[keys4](https://github.com/nikitasolonukha/keys4) содержит один HTML с Plotly, линейными функциями, пятью traces, hover, legend и zoom/export controls. Backend отсутствует. Коэффициенты и вычисления взяты из исходного задания: D₁=120−8P, D₂=140−8P, S₁=20+12P, S₂=10+12P.

## VERIFIED

Проверены исходные формулы: E₁=(80;5), E₂=(88;6,5), количество +10%, цена +30%. Это вывод из заданных уравнений, не экономический прогноз. HTML содержал устаревшие числа в fallback-разметке, но исходный JavaScript уже обновлял их после загрузки — это не заявляется как найденная ошибка расчёта.

QA 390/768/1440: пять traces, координаты, legend toggle, reset, смена размеров. Исправлено сохранение старой ширины SVG после сужения окна. График работает без CDN: библиотека Plotly сохранена локально.

## PORTFOLIO POLISH

Редакционная композиция, читаемые подписи, мягкая бумажная палитра и два различимых цвета кривых. Исходные функции и данные сохранены. Layout графика заменён, добавлена явная кнопка сброса вида. Полный набор кривых, легенда, наведение, zoom и результаты присутствуют в master.

## DEMO / MOCK

Вся модель условная и учебная. Нет настоящих цен, продаж, пользователей или утверждений о реальном рынке. UI не сгенерирован изображением — это работающий Plotly.

## НЕ ПРОВЕРЕНО

Точная роль Никиты в учебном задании требует подтверждения. Это небольшой технический проект, а не коммерческая аналитическая платформа. Новые модели, прогнозирование и редактирование коэффициентов не добавлены.
