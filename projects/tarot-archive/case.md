# Лендинг таро-бота

**READY — архивный редакционный кейс. Авторство подтверждено Никитой; исходный runtime не восстановлен.**

## Что это

Лендинг создавал атмосферный вход в Telegram-сценарий через свет, туман, золото и реакцию на курсор.

## ORIGINAL

Историческая карточка фиксирует Next.js/React, CSS glow/blur/fog, parallax, mouse tracking и SVG/Canvas-графику.

Заявленная технология: Next.js · React · Tailwind · CSS motion.

## VERIFIED

Сохранены карточка и обложка из прежнего портфолио. Пользователь подтвердил, что проект выполнен им. Архивная обложка используется только как иллюстрация и не выдаётся за снимок интерфейса.

## NOT VERIFIED NOW
