# Контактная визитка — экран и печать

**READY — локальный обезличенный пакет.**

## ORIGINAL
Desktop/МОЕ/ПАПА визитка: vizitka.html, vizitka_hd.html, round_photo.py. Небольшая статическая работа HTML/CSS: двухколоночная композиция, фотография в круге, имя/должность/контакты, mail/tel/web ссылки, print styles. HD-макет имеет размер 1920×1067 (примерно 9:5). Python-скрипт подготавливает круглую фотографию. Это не CRM и не многоэкранное приложение.

## VERIFIED
Исследованы структура и стили двух HTML-вариантов; manifest содержит SHA. Обезличенная копия проверена на 390/768/1440, clipboard, раскрытие пояснения, отсутствие JS errors/overflow. Реальный PDF создан Chromium print CSS и скачан через UI, сигнатура %PDF проверена. Print-preview сохранён отдельно.

## PORTFOLIO POLISH
Сохранены исходные серо-синие поверхности, композиция, пропорции двух колонок и тонкий вертикальный разделитель. Для web добавлен адаптивный вертикальный вариант; исправлены фиксированные размеры HD на узком экране. Копирование контакта, экран пояснений и PDF-ссылка — новые средства локальной презентации, не исторические функции.

## DEMO / MOCK
Реальные имя, фотография и семейные контакты не скопированы в demo. Используются вымышленный Алексей Лесной, монограмма, зарезервированный домен .example и заведомо демонстрационный телефон. Скопировать значение можно, позвонить/отправить сообщение из демо нельзя. Это макет, не визитка реального клиента.

## Ограничения
Авторство и разрешение на публичный показ исходной семейной версии не подтверждены. Сам исходный код и личные данные не включаются в публичный пакет автоматически. Ценность работы ограничена аккуратной HTML/CSS и печатной компоновкой; backend и бизнес-метрики не заявляются. Переосмысление не требовало внешних референсов: исходный характер сохранён.
