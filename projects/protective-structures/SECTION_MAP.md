# KONTUR · section map

| Section | Composition | Purpose |
|---|---|---|
| 01 · Hero | Full-width typography → full-bleed media reveal | Сразу назвать инженерное решение и показать его физический масштаб без split-композиции. |
| 02 · Principle | Full-bleed image + three unboxed statements below | Объяснить принцип пассивной защиты одним визуальным жестом. |
| 03 · Solutions | Horizontal media strip, unequal crops | Показать проектирование, производство, монтаж и обслуживание через процесс и материалы. |
| 04 · Industries | Horizontal snap gallery | Дать каждой отрасли отдельное окружение, не превращая раздел в каталог карточек. |
| 05 · Why KONTUR | Panoramic detail + three editorial columns | Отделить аргументы от визуала и сохранить спокойный темп. |
| 06 · System | Interactive full-width technical canvas | Главный product interaction: выбор элемента меняет visual и описание. |
| 07 · Process | Five stacked horizontal bands | Показать этапы как непрерывную инженерную последовательность. |
| 08 · Business value | Type-only statement field | Зафиксировать пользу без декоративных KPI и очередного изображения справа. |
| 09 · Company | Full-bleed material image with caption overlay | Вернуть человеческий/производственный контекст без обычного split. |
| 10 · Request | Full-width image-backed CTA | Связать расчёт с конкретным стальным узлом. |
| 11 · Contact | Single-column form + compact information rail | Завершить сценарий понятным действием и не повторять split-секцию. |

Обычная композиция «текст слева / изображение справа» не используется. Единственная двухчастная рабочая зона — интерактивная техническая схема, где разделение обусловлено функцией.
