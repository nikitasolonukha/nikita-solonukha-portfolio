# KONTUR — защитные сетчатые системы для промышленных объектов

Одностраничный B2B-сайт объясняет инженерное решение: что защищается, из чего состоит система, как проходит проектирование и как запросить расчёт.

## ORIGINAL

Локальный проект `Kontur БПЛА`: Next.js 16, React 19, TypeScript, Tailwind CSS 4, Framer Motion. В исходнике 11 содержательных секций, адаптивная навигация, интерактивный разбор состава системы и контактный modal. Runtime-изображения локальные. Никита подтвердил авторство проекта.

## VERIFIED

Изучены код, README, дизайн-описание и существующие QA-отчёты. Архивный visual QA охватывает 375, 390, 1024, 1440 и 1920 px; в отчёте horizontal overflow отсутствует. Сохранены настоящие кадры desktop/mobile, меню, состава системы, услуг и формы.

## PORTFOLIO POLISH

Для кейса отобраны кадры, которые показывают продукт целиком: hero → принцип работы → услуги → отрасли → преимущества → конструкция → процесс → ценность → компания → контакт. Интерфейс проекта не перерисовывался нейросетью.

## DEMO / MOCK

Название, телефон, почта, изображения объектов и контактная форма относятся к демонстрационному лендингу. Форма не отправляет данные на сервер. Изображения используются как иллюстративный material и не подтверждают реально построенные объекты.

## PLANNED / ограничения

Производственные расчёты, сертификаты, реальные объекты, CRM-интеграция и отправка заявки не проверены и не заявляются. Это frontend-проект и продуктовая презентация инженерной услуги.

## SCREEN → ACTION → STATE → RESULT

1. Первый экран → понять предложение → protected industrial site → перейти к устройству системы.
2. Состав системы → выбрать элемент → активный technical detail → увидеть назначение узла.
3. Навигация → открыть отрасли / процесс → нужная секция → оценить применимость.
4. CTA → открыть форму → modal → заполнить контактные данные локально.
5. Mobile menu → раскрыть навигацию → полноэкранное меню → перейти к разделу.

## Visual redesign V2 — в работе

Локальная demo-копия `work/bpla-preview` получила новое направление первого экрана: панорамный визуал конструкции сверху, техническое предложение на светлой поверхности ниже, натуральный стальной/песочный цвет вместо лаймового акцента и обычная гарнитура вместо декоративного курсива. Это иллюстративный материал, а не фотография построенного объекта. В секции принципа работы общий кадр заменён близким видом сетчатого полотна, чтобы не повторять hero и показывать устройство. Сохранены настоящие 11 секций и выбор узлов системы. `hero-v2-*`, `system-v2-*`, `master-v2-*` и `redesign-v2-capture-qa.json` фиксируют 1440/390, шесть главных сцен, 0 ошибок страницы, 0 overflow и 0 битых изображений; 768 проверен вручную. Lint проходит. Production build окружения падает на Turbopack symlink, webpack компилирует код и TypeScript, но prerender останавливается на ошибке внутреннего макроса Next; dev preview работает. Art direction остаётся IN PROGRESS до прохода остальных секций и сборочного исправления.
