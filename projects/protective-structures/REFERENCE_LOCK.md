## Why this reference

Base Create строит страницу последовательностью «типографический вход → крупное движущееся медиа → полноширинное statement → свободная сетка работ → масштабный финал», а не повторяющимися split-блоками. Для KONTUR это даёт способ сделать инженерную конструкцию главным материалом сайта. AVVR нужен для длинной профессиональной информационной архитектуры: спокойная смена тёмной и светлой поверхностей, человеческий масштаб, предметная иллюстрация и подробный footer без ощущения SaaS.

## Reference section map

- **MY HERO** ← Base Create: типографический экран занимает всю ширину; визуал конструкции появляется отдельным полноширинным слоем, а не справа от текста.
- **MY SECTION 02** ← AVVR: одно крупное реальное/иллюстративное медиа ведёт к трём коротким принципам без карточечной рамки.
- **MY SECTION 03** ← Base Create work grid: изображения решений формируют ритм, подписи остаются вторичными и стоят на общей базовой линии.
- **MY SYSTEM EXPLAINER** ← AVVR expertise section: светлая техническая поверхность после тёмного вступления; схема и выбор узлов читаются как рабочий материал.
- **MY PROCESS** ← Base Create statement rhythm: каждый этап получает крупный номер и отдельную горизонтальную полосу вместо вертикального timeline-компонента.
- **MY GALLERY** ← Base Create media scale: один панорамный кадр, затем два кропа деталей разного масштаба.
- **MY INTERACTION** ← существующий выбор элемента конструкции; active state меняет крупный visual и пояснение без декоративных эффектов.
- **MY MOBILE** ← AVVR: сохраняется крупный заголовок, полноширинное изображение и последовательный single-column flow; вторичная навигация уходит в menu.

## Signature interaction

Интерактивный разбор конструкции: пользователь выбирает несущий каркас, сетчатое полотно, опоры, крепёж и инженерный контур. Меняются крупное изображение, подпись и техническое пояснение. Это существующая функция KONTUR и главный product moment.

## Three wow moments

1. Полноэкранный типографический вход, который на scroll открывает широкую защищаемую зону.
2. Интерактивный технический разбор пяти элементов системы на светлой инженерной поверхности.
3. Переход от панорамы объекта к крупным материальным деталям и процессу проектирования.
