# Solonflow — архив личного портфолио

**READY — локальный архивный пакет, три версии одного портфолио.**

## ORIGINAL
Три найденных репозитория представляют личное портфолио одного автора: site-avito (Next.js, страницы о себе/проекты/контакт), Site-DigitalTranformation (React/Vite, одностраничный каталог и 3D) и solonflowai-portfolio (развитие React/Vite с локализацией, фильтрами и расширенными кейсами). Это объединение по назначению, имени владельца и повторяющемуся каталогу, не утверждение общей git-истории. Все три строки и отдельные manifests сохранены; они не считаются тремя независимыми клиентскими продуктами.

В основной версии: React 18, TypeScript, Tailwind 4, Framer Motion, Three.js/R3F/Drei, GSAP; фильтры, grid/show more, планеты для выбора проекта, modal, RU/EN с localStorage, мобильное меню, contact/clipboard, policy/terms/404. Нет собственного рабочего backend контактной формы. Исторические маркетинговые показатели не являются проверенными результатами.

## PORTFOLIO POLISH
Новая типографическая главная, компактная навигация, спокойный графитовый фон, предметные тексты и реальные screenshots уже проверенных проектов. Убраны неподтверждённые uptime/скорость/бизнес-метрики и неверный Next.js-тег LexLegal; технические теги сверены с отдельными кейсами. Подборка ограничена десятью исследованными предметами, NDA и несопоставленные работы в её данные не включены.

Сохранены исходные фильтрация, модель данных, language context и 3D-режим; grid выбран по умолчанию. Переписаны presentation-компоненты hero/about/services/contact/header/404. Исправлен исходный непрозрачный слой, который закрывал изображение в modal; добавлены dialog semantics, focus trap/return и Escape. Мобильные карточки выстроены вертикально. Служебная 404 получила спокойное оформление вместо glitch-терминала.

## DEMO / MOCK и ограничения
Главная — современная локальная презентация старого портфолио, не утверждение о его прежнем внешнем виде. Картинки проектов включают portfolio-polish/demo UI из соответствующих пакетов. Портрет взят из архива; его фотографическая подлинность не проверялась, исходная отметка изображения сохранена. Это не доказательство реальной фотосессии.

Privacy/terms — исходные страницы, не юридически проверенные документы для нового сайта. Исторические screenshots ранних версий могут содержать старые неподтверждённые заявления; оставлены локально исключительно для исследования. Контактный сценарий копирует почту, ничего не отправляет. Приватный доступ к репозиториям не разрешает публикацию их содержимого. Окончательное авторство отдельных работ определяется их case.md.
