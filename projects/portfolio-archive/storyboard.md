# Storyboard — Solonflow / архив портфолио

Основной flow: hero → направления → о работе → каталог → фильтр → проект → возврат → все проекты → 3D на desktop → язык → контакты → служебная страница.

| Ориентир | Экран / действие | Результат |
|---|---|---|
| 00–05 | Главная | Типографика и позиционирование |
| 05–12 | Направления / о работе | Предметное описание, фото |
| 12–18 | Каталог, фильтр Веб | Три работы |
| 18–24 | Открыть LexLegal | Подробности, scroll, Escape |
| 24–30 | Все / показать ещё | Полная подборка |
| 30–38 | 3D → Grid (desktop) / меню (mobile) | Альтернативная навигация |
| 38–45 | English → Russian | Исходный language context |
| 45–52 | Контакты → скопировать email | Только clipboard, без сообщения |
| 52–60 | Политика → 404 → главная | Служебные маршруты |

QA отдельно: все фильтры, пустая категория, каждый проект, focus/Escape, 390/768/1440, целостность изображений, scroll overflow, язык после reload. Старые версии архивируются отдельно; актуальная демонстрация не выдаётся за исторический дизайн.
