# Портной — сценарий master walkthrough

Запись настоящего локального интерфейса. Только исходный demo seed и вымышленные новые материалы. Внешние подключения отключены. Общая цель: показать цикл работы ателье, а не только главную.

| Порядок / ориентир | Экран → действие → состояние → результат |
|---|---|
| 00:00–00:05 | Рабочий стол → обзор → материалы и сохранённые варианты → понятно назначение продукта |
| 00:05–00:13 | Каталог → поиск ткани по артикулу → отфильтрованный результат → открыть паспорт ткани |
| 00:13–00:18 | Паспорт → свойства материала → состав, плотность, цена → выбор для костюма |
| 00:18–00:38 | Конфигуратор → выбрать ткань и параметры → обновляемый 2D-чертёж → сохранить именованный вариант |
| 00:38–00:48 | Варианты → выбрать два → сравнение → различия ткани и конструкции |
| 00:48–01:05 | Импорт → загрузить подготовленный CSV → сопоставление и проверка → две ткани добавлены в каталог |
| 01:05–01:15 | Создание ткани → заполнить поля → сохранить → паспорт новой ткани |

Сразу после master в кейсе показан отдельный 10-секундный 3D feature clip: переход в «3D студию», крупный вид костюма, переключение ракурсов и материала. 3D не подменяет 2D-конструкцию: геометрические варианты костюма в модели не реализованы. Источник сторонней модели и это ограничение указаны рядом с материалом.

Хронометраж ориентировочный; фактические моменты переключения будут сохранены в capture-report.json. На телефоне показанные разделы прокручиваются до ключевых действий. Desktop — MacBook; mobile — iPhone, без искажения пропорций.
