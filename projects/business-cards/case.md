# BusinessCards — платформа визиток

**Статус: READY (локальный пакет).**

Кабинет для управления сайтами-визитками компаний: создать карточку, изменить сведения, получить публичную ссылку и посмотреть статистику. Это небольшой SaaS с frontend, Go API и Telegram webhook.

## ORIGINAL

[Репозиторий](https://github.com/nikitasolonukha/business-cards-platform), commit `41863cef24a04c99b79daff49068212c45ab71fa`. React 18, Vite, React Router, Tailwind; backend Go/Gin, GORM/MySQL, JWT, rate limiting, middleware ролей и владельца, health/readiness, Telegram webhook.

По коду реализованы регистрация/вход, CRUD визиток, публичная выдача, счётчики page_views/telegram_views. Frontend содержит поиск, фильтры, подтверждение удаления, копирование ссылки, редактор и статистику. Настройки — исходная заглушка, а не готовая функция.

## VERIFIED

Прочитаны README, routes, модели, frontend, HTTP-клиент, auth context, обработчики статистики и публичной карточки. Безопасно запущена отдельная локальная копия frontend. Полный пользовательский flow проверен на 390/768/1440: вход, поиск, пустой результат, фильтр, создание, сохранение после reload, редактирование, публичная карточка, отмена удаления по Escape, удаление и 404. Ошибок страницы и внешних обращений в прогоне нет.

## PORTFOLIO POLISH

Графитовая основа и тёплый медный акцент, контрастная типографика, более спокойные карточки. Убраны градиентные свечения, blur и декоративный фон. Исправлены конфликт proxy `/card` с `/cards/new`, доступные имена полей, название выхода из аккаунта и native modal с Escape/focus. Исходники и production не менялись.

Референсы: [HiHello](https://www.hihello.com/) — карточка и измерение взаимодействий; [Blinq](https://blinq.me/) — понятная идентичность и контактный сценарий; [Carrd](https://carrd.com/) — компактная публичная страница. Изучены как направления; их функции, код, изображения и метрики не переносились в кейс.

## DEMO / MOCK

Локальный адаптер повторяет существующий контракт frontend и сохраняет карточки в localStorage. Auth имитируется; серверные JWT/MySQL/Telegram не запускаются. Четыре компании, домены `.example`, имена и все показатели вымышлены. Конверсия вычисляется существующим frontend из подготовленных чисел. Публичная выдача исключает поле demo-токена. Счётчики в этой версии статические и не выдаются за реальные результаты.
