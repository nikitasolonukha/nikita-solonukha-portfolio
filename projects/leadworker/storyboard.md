# Leadworker — технический walkthrough

План: 30–45 секунд, 1440×900 / 390×844.

| Экран | Действие | Состояние | Результат |
|---|---|---|---|
| Локальный стенд | Прочитать входные параметры | Вымышленный адресат | Telegram отключён |
| Username | Проверить | Resolve → mock transport | HTTP 200, username |
| Fallback | Выбрать второй сценарий | Username error → InputPeer | HTTP 200, input_peer |
| Без подсказок | Проверить | Невозможно адресовать | HTTP 400, no_peer_hints |
| Таймаут | Проверить | Ожидание > лимита | HTTP 504 |
| Нет доступа | Проверить | Bearer отклонён | HTTP 401, транспорт не вызван |

Состояния missing/empty/method также проверяются API QA. Панель не существовала в оригинальном backend: создана специально для технической демонстрации. Настоящего получателя/отправки нет.
