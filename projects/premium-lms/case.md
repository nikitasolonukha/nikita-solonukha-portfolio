# Академия — образовательная платформа (LMS)

**Статус продукта: готова к развёртыванию, не размещена в интернете.** Публичная презентация построена на скриншотах из собственного QA-пакета проекта.

Русскоязычная LMS на Next.js, TypeScript и Supabase. Владелец создаёт структуру курса, редактирует уроки из 11 типов блоков, загружает материалы, публикует редакции и назначает обучение через админ-панель. Ученик проходит программы и уроки, сохраняет материалы и видит свой прогресс.

## ORIGINAL

[Репозиторий premium-lms](https://github.com/nikitasolonukha/premium-lms) — публичная поставка: исходники, миграции Supabase, тесты, документация и QA-материалы. Credentials, локальная база, загруженные приватные файлы, зависимости и результаты сборки в Git не входят.

Роли: Student (опубликованные программы, прогресс, сохранённое), Editor (черновики, структура и материалы; обязательный TOTP), Admin (публикация, пользователи, роли, доступы, категории, бренд, аналитика, аудит; обязательный TOTP). Editor не изменяет редакцию, которую видят ученики; последний действующий Admin защищён от отключения и понижения.

## VERIFIED

Источник: `docs/QA_REPORT.md` в репозитории, аудит от 30 сентября 2026. Все цифры взяты из отчёта и привязаны к сохранённым evidence-файлам проекта.

- единый финальный прогон Playwright: 19/19, без skipped и retries;
- 28 unit-тестов (строки 95,89 %, ветви 95,63 % для выбранных доменных модулей, не для всего UI);
- 32 прямых security-сценария: anon, Student A/B, Editor, Admin, staff без AAL2; RLS, закрытый Storage;
- видео: YouTube, Vimeo, Rutube, прямой MP4 и разрешённый внешний iframe проверены в реальном Chrome;
- 63 проверки доступности (Axe WCAG 2.1 AA) без нарушений; 21 экран × 7 размеров = 147 проверок адаптива без горизонтального переполнения;
- нагрузка по структуре: 300 уроков и 299 завершений, курс из 21 модуля и 63 уроков;
- Windows standalone и Linux-контейнер: сборка и runtime smoke прошли.
