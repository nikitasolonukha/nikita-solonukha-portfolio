# STEP — reference lock

## Product reference

- **stoic. features:** https://www.getstoic.com/features

The reference is used for calm consumer-product rhythm: one daily action at a time, readable reflection states and large real app imagery. STEP keeps its own tree, character, dark forest palette and Telegram Mini App structure.

## Section map

- **Hero** ← the actual home screen is the central object; typography sits around it rather than replacing it.
- **Flow** ← one uninterrupted desktop walkthrough demonstrates state changes.
- **Mobile** ← the same recording remains a true 390 px product surface.
- **Route proof** ← all 20 screens appear in one dense audit sheet instead of a set of feature cards.
- **Details** ← progress dominates; completion and chat sit as smaller supporting states.
- **Boundary** ← Original / Portfolio polish / Demo remain visibly separated.

## Interaction lock

The signature interaction is the tree/progress loop: complete a material or water the tree → local balance/history changes → achievement or streak state updates.
