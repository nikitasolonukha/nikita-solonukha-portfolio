# StepByStep — storyboard перед записью

Мобильный мини-app, исходный характер (дерево, персонаж, бирюзовый акцент) сохранён. Главная запись 70–100 секунд, дополнительные экраны — отдельная запись. Не выдаём подготовленные данные за историю реального пользователя.

| Экран | Действие | Состояние / результат |
|---|---|---|
| Главная | Обзор дерева и счётчиков | Подготовленный локальный профиль |
| Заметки | Создать заметку, сохранить | Запись появилась в списке |
| Прогресс | Календарь, оценки и графики | Синтетическая недельная история |
| Цели | Добавить цель | Та же цель доступна в ритуалах |
| Вода | Выбрать объём, полить | Списаны монеты, записан день |
| Статьи | Открыть материал, отметить | Награда за выполненное задание |
| Чат | Ввести сообщение | Исходный шаблонный ответ, без AI |
| Дополнительно | Просмотреть библиотеку | Существующие разделы |
| Настройки | Изменить время | Локальное сохранение, без push |

Дополнительная запись: достижения, монеты, SOS (честное состояние незавершённого раздела), аудиоплееры с демонстрационной дорожкой, сон/стресс, база знаний, программа, обратная связь, информация о приложении. Внешние ссылки не активируем, сообщений не отправляем.

Экранная карта и первичный обход 20 маршрутов × 390/768/1440: `work/step-survey/report.json`. Запись начинается только после проверки основных действий.
