# Автоматизация Twitter / X — наблюдаемая обработка сценариев

Основная портфолио-страница: `site/case-twitter-automation.html`. Она показывает X-подобный результат локального replay в контексте исходного Python CLI и прямо отмечает отсутствие записи живого аккаунта X.

**READY — локальный пакет, без внешних действий.**

## ORIGINAL
Найден рабочий Python-проект в РАБОТА/Приложения/скрипт твиттер 2. README описывает чтение списка групп, правило 1/N, текст и GIF, поиск участников относительно собственного сообщения, переход к публикациям и запуск Windows Scheduler. Код разделён на navigation, sender, participant_finder, retweeter, group_parser, group_processor, auth, конфигурацию и CLI. Это CLI-автоматизация, а не готовый web-продукт. 15 файлов скопированы в изолированный аудит, SHA256 сохранены. Клиентские groups/config/session/GIF не читались и не копировались.

## VERIFIED
Неизменённый класс GroupProcessor извлечён AST и исполнен с подменёнными зависимостями. Отдельно извлечён исходный extract_retweet_count. 9 контрактных проверок PASS: полный/частичный/нулевой результат, отсутствие правила, ошибка отправки, закрытый браузер, числовое/отсутствующее/нулевое правило. Полный проход даёт 3 mock-действия; частичный 2. Реальных сетевых обращений нет.

## PORTFOLIO POLISH
Dashboard-first панель заменена на X-first presentation: сообщество, исходное сообщение, три профиля и статусы mock-repost занимают основной экран. Контроллер безопасного replay остаётся вспомогательным справа, а исходный trace открывается в drawer. На mobile показывается X-feed и отдельный automation sheet. Это новый presentation layer, не запись живого X.

## DEMO / MOCK
Все browser/transport объекты и участники вымышлены. Домены social.example, никакие аккаунты не открываются. Сервер принимает только один из шести заранее определённых режимов. Задержка UI 450 мс показывает состояние обработки; это не измерение производительности исходного продукта. История — память вкладки, не исходная БД. Панель нельзя использовать для живых отправок.

## Ограничения исходного кода
Нулевой результат может вернуть True без failed; частичный успех увеличивает success для целой группы; extract_retweet_count принимает 1/0. Панель честно отражает эти исходные значения. Реальный DOM X, pinned/last fallback, расписание Windows, авторизация, загрузка GIF и Google Sheets не проверялись. Объём личного вклада и публичные права требуется подтвердить. Никаких заявлений о росте охватов или рабочей production-надёжности.
