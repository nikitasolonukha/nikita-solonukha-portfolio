# Telegram Intel

**Статус: READY (локальный пакет).** Приватный исходник; локальный пакет, не публикация.

Мониторинг каналов для человека, который следит за профессиональными темами: лента, поиск, сигналы, ключевые слова и источники в одном Telegram Mini App.

## ORIGINAL

Исследован приватный telegram-intel-bot, commit 480eac969367203774c21f73d24aee9a0f1b52b8. React 18/TypeScript/Vite; FastAPI, SQLAlchemy, SQLite/PostgreSQL; Telegram Bot API и Telethon; опциональные Meilisearch и OpenAI summaries. Исследованы модели, маршруты, search/hot score, dedup, alerts, topics, frontend и тесты.

README перечисляет восемь вкладок, но актуальный frontend содержит пять разделов: Сегодня, Лента, Поиск, Уведомления, Профиль. Горячее/Сигналы находятся внутри Ленты, темы/источники/расписание — в Профиле. Кейс показывает эту фактическую структуру.

## VERIFIED

45 исходных тестов dedup, Telegram auth, trending, signals и search_index прошли. Тесты seed с оригинальными данными и импорты внешнего Telegram pipeline в этот прогон не включались. API работает локально с реальной SQLite и исходными маршрутизаторами/сервисами.

Браузерный QA 390/768/1440: чтение, сигналы, поиск и пустой результат; создание, выключение, сохранение после reload и удаление уведомления; создание/удаление подписки; выбор тем; расписание; включение источника. Глобального переполнения нет. TypeScript проверен; исправлено отсутствовавшее поле digest_hour_utc в типе ответа. Vite build проходит.

## PORTFOLIO POLISH

Графитово-зелёное рабочее пространство. На desktop боковая навигация, на телефоне нижняя. Лента выделяет источник и текст, а не цветные рамки. Читаемые формы, фокус, кнопки, адаптивные списки, переход к началу раздела. Добавлено раскрытие уже имеющегося текста публикации — изменение presentation layer, которого не было в исходном UI.

Изучены [Feedly: источники](https://docs.feedly.com/article/768-follow-sources-in-feedly), [Inoreader: автоматизации](https://www.inoreader.com/blog/2026/01/save-time-with-automations.html), [Readwise Reader](https://readwise.io/read). Ориентиры: спокойная лента, отдельная навигация, ясное разделение поиска и правил. Их код, тексты и изображения не использованы.

## DEMO / MOCK

Новая отдельная база: четыре вымышленных источника, двенадцать подготовленных публикаций, профиль 900200. Показатели считаются из этих данных; не являются метриками реального использования. Telegram identity dependency заменена фиксированным demo-пользователем. Telegram SDK отключён; бот, ingest, доставка, расписание отправки и внешние AI-сервисы не запускаются. Сохранение расписания проверено, доставка дайджеста не заявляется.

Реальный код выполняет CRUD, SQL fallback поиска, ранжирование и сохранение. Не используются реальные клиентские данные, сессии, cookies или секреты.

## НЕ ПРОВЕРЕНО / ОГРАНИЧЕНИЯ

Production Telegram auth и доставка, PostgreSQL, Meilisearch в работе и AI-резюме не проверены. Исходная авторизация допускает guest при отсутствии token, а переключение источников доступно любому authenticated user: это ограничения исходной модели доступа, не гарантия production security. Публичный показ приватного продукта и точную роль Никиты нужно подтвердить. Ничего не опубликовано.
