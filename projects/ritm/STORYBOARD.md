# Ритм — полный master walkthrough

Используем встроенный demo mode в новом браузерном профиле. demo-fixture.json — подготовленные демонстрационные данные, а не назначенная программа или реальные результаты пользователя.

| Экран | Действие | Состояние → результат |
|---|---|---|
| Сегодня | Открыть день, отметить привычку | 0% → 20%, следующее действие |
| Тренировки | Открыть программу | Список → состав программы |
| Сессия | Начать, открыть вес, отменить изменение | Активная тренировка, доступный редактор |
| Подход | Записать 6 повторений | Сохранённый подход → отдых |
| Отдых | Пропустить | Следующий подход |
| Упражнения | Завершить 4 подхода × 3 упражнения | Смена упражнения и прогресс сессии |
| Завершение | Подтвердить | Итог с фактически записанными подходами |
| Прогресс | Открыть | Показатели после записи |
| Журнал | Открыть | Сохранённая тренировочная запись |
| Настройки | Привычки → программа → раскрытие | Настройки и структура программы |

Паузы 1–3 секунды, запись реального движения интерфейса. Обе версии записываются отдельно в 1440×900 и 390×844. Фактический тайминг — capture-report.json. Внешние запросы блокируются; синхронизация Supabase/Telegram не выдаётся за проверенную.
