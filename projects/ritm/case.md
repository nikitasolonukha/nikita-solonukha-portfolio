# Ритм — личный трекер

**Фактический пакет: READY; ART DIRECTION V2: IN PROGRESS.**

PWA для плана дня, привычек, тренировок и наблюдений. Кейс показывает план дня, отметку привычки, тренировку, итог, прогресс, журнал и настройки. По запросу пользователя интерфейс переработан в текущей задаче; исходник репозитория сохранён отдельно.

## Проверено в локальном демо

Запуск программы, запись 12 подходов по 6 фактических повторений, пропуск отдыха, переход между упражнениями и подтверждение завершения. Использованы локальные demo-данные: привычки с расписанием и названия упражнений, соответствующие исходным идентификаторам тренажёров; рабочие веса не выдумывались. Это демонстрационные записи в новом браузерном профиле, а не результаты пользователя или рекомендации по тренировке.

Производственная сборка и все 58 тестов из команд проекта прошли. Проверки охватывают доменную логику, восстановление состояния, сценарии синхронизации и тренировочные сессии. SQL-файлы читались тестами как текст; миграции не запускались. Видеозапись показывает интерфейс после действий, 60 fps, с паузами для чтения.

## Архитектура по коду

Next.js 15, React 19, TypeScript, Lucide. Локальное состояние и очередь команд, идентификаторы команд для идемпотентности, журнал тренировок, таймер отдыха, расчёт объёма по подтверждённым подходам. Есть код клиентской/серверной синхронизации, Supabase и Telegram, SQL-миграции и PWA shell. Эти внешние интеграции не проверены реальными ключами; работа в production не утверждается.
