# Nikita Chat — личные заметки

**Статус: READY (локальный пакет).** Компактный учебный web-продукт.

Однопользовательский чат: написать сообщение, сохранить и увидеть историю после перезагрузки. Такой объём честно показывает интеграцию frontend и REST API, без обещаний полноценного мессенджера.

## ORIGINAL

[testsergey](https://github.com/nikitasolonukha/testsergey), commit 14a68222fc29c06bb8216e55ad0a5770bd536bea. React/TypeScript/Vite, Axios, Tailwind; Vercel serverless handler и KV, uuid. Исследованы PLAN/RETROSPECTIVE, API и все компоненты. Автор всех сообщений в типе — `me`; другие собеседники, WebSocket и несколько чатов не реализованы.

## VERIFIED

Исходный handler исполняется локально, заменены только импорты KV и UUID: JSON-файл вместо облачного хранилища и crypto.randomUUID. Его проверки запроса сохранены. Проверены GET/POST, 400 для пустого/нестрокового/>2000 сообщения, 405 для неподдерживаемого метода. TypeScript и Vite build проходят.

UI QA 390/768/1440: пустое состояние, сохранение, reload, многострочный ввод, 2000 символов, сбой POST с сохранением черновика, успешный повтор. Нет page errors и горизонтального переполнения. Тестовые строки границ не включены в master.

## PORTFOLIO POLISH

Спокойный тёмный интерфейс личных заметок. Локализованы тексты, добавлены имена элементов для доступности, учтён IME при Enter. Убраны конфликтующие вложенные контейнеры: заголовок и поле ввода не сжимаются длинной историей. Список прокручивается внутри рабочей области, а не сдвигает всю страницу. Визуальная версия отдельно от исходного репозитория.

## DEMO / MOCK

Подготовленные заметки о прототипе и портфолио. Локальный JSON KV, демонстрационный отказ 503 только для проверки повтора. Сообщения никому не отправляются и в Telegram не попадают. «Личные заметки» — название presentation-версии, исходный заголовок Nikita Chat.

## НЕ ПРОВЕРЕНО / ОГРАНИЧЕНИЯ

Облачный KV и production deployment не проверены. Исходный GET → SET не атомарен при конкурентной записи, несмотря на комментарий в коде. Нет пользовательской авторизации и изоляции нескольких пользователей; кейс не называет проект production-мессенджером. Личную роль Никиты необходимо подтвердить.
