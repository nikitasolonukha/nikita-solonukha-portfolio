# GIGANT — управляемое выполнение задач агентом

**READY — локальный пакет; права на публикацию не подтверждены.**

Задача продукта — провести запрос через план, инструменты и проверку результата. Сильная часть для показа: агент останавливается перед действием плана, пользователь разрешает его либо отклоняет, выполнение продолжается с сохранённым состоянием.

## ORIGINAL
Локальная папка МОЕ/ИИ агенты/Гигант: FastAPI, AgentLoopService, chat schemas, tool executor/registry, continuation tokens, traces, memory и orchestration. README описывает связку с Open WebUI, LiteLLM, Redis и браузерными инструментами. В изолированную копию перенесены только 205 Python-файлов и описание зависимостей; env, runtime logs, пользовательские файлы и host bridge не переносились. Хеши в source-manifest.json. Принадлежность папки сама по себе не доказывает личное авторство всех компонентов; роль и право публикации остаются вопросом.

## VERIFIED
61 исходный тест test_agent_loop.py и test_agent_confirm.py прошёл с заблокированными внешними соединениями и HTTP. Проверены предел шагов, разбор ответа, восстановление плана, обязательные действия, pause/approve/reject, подпись и срок continuation token. Это выбранная часть тестов, не весь проект.

Локальная API-обвязка вызывает настоящий AgentLoopService.run и resume_after_confirmation. Три разрешения выполняют browser.open_url, browser.extract_text, file.write_file; затем движок сам вызывает file.read_file для проверки результата. Это важная граница: confirm не означает отдельное разрешение абсолютно каждого внутреннего tool call. В сценарии отказа до первого шага инструменты не вызываются.

## PORTFOLIO POLISH
Новая отдельная панель для демонстрации, не оригинальный Open WebUI: задача, прогресс, разрешение/отказ, результат, скачивание, журнал и границы среды. Графитовые поверхности, медный акцент, компактная типографика. Интерфейс и история в памяти процесса добавлены для кейса; не выдаются за ранее поставленный функционал.

## DEMO / MOCK
Исходные StubChatService и StatefulToolExecutor из тестов. Модель получает заранее подготовленные ответы, browser возвращает вымышленный бриф студии «Север», file хранит строки в словаре Python. Внешний сайт, команды ОС и настоящая файловая система инструментами не используются. Задержки в UI — только короткая презентационная пауза. Скачивание выдаёт действительно созданное значение из памяти. Метрики бизнеса не придуманы.

## PLANNED / не проверено
Живые LLM, Open WebUI, Redis/долгосрочная память, мультиагентный режим, scheduler, host bridge, production auth и реальные browser/code tools не запущены. Наличие модулей в исходнике не означает успешной интеграционной проверки. Публичная публикация не выполнялась.
