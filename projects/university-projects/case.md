# Университетские проекты

Это **редакционный umbrella-case из трёх отдельных учебных работ**, а не один технический продукт или коммерческий заказ. Авторство работ подтверждено Никитой.

## 1. Защищённые сообщения

Архивная карточка описывает Python/Tkinter/Flask, обработку и шифрование сообщений, web и admin-компоненты. Исходная реализация и новая запись интерфейса не найдены. [Подробный архив](../protected-messages/case.md).

## 2. Анализ и визуализация данных NPM

Архивная карточка описывает Requests/Pandas/NumPy/Matplotlib, NPM Downloads API и расчёт статистик. Notebook, dataset и runtime не найдены. [Подробный архив](../npm-data-analysis/case.md).

## 3. Университетский Telegram parser/search

Репозиторий `parser-tg-muiv`, commit `654ae68`: найден Python-код Telegram-бота, Telethon parser, SQLite и поиск по сохранённым сообщениям. Исходный Telegram screenshot/video не найден. Этот бот отличается от личного AI News Digest в разработке; он также описан в [кейсе Telegram News](../news-aggregator-archive/case.md).

## Граница доказательств

Схема на обложке — редакционная типографика. Она не является скриншотом продукта. Учебные части показаны раздельно; отсутствующие runtime и Telegram UI не заменены вымышленными панелями.
