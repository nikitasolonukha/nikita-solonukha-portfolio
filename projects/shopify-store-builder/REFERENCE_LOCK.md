## Why these references

FABRIC treats typography as structure: long sequences move between type-only declarations, lists and dense information without falling into a card grid. Base Create uses bold image-led chapters, large statements and clear changes of pace. Lumina applies those spatial ideas to one real object: the lamp photograph determines crop, scale and the transition between sections.

## Reference section map

- **Hero** ← one image owns the viewport; title crosses the object instead of sitting in a separate column.
- **Manifesto** ← type-only statement resets the pace after the hero.
- **Object anatomy** ← sticky media and changing content replace feature cards.
- **Image sequence** ← two unequal crops and one oversized word create product rhythm.
- **Purchase** ← one three-part commercial scene: proposition, object, action.
- **Catalog / PDP** ← functional commerce screens keep the same editorial scale.
- **Interaction** ← Shape / Focus / Presence changes the main media and explanation.
- **Mobile** ← chapters stack in the same narrative order; the object remains large and controls stay full width.
