# Copilot — четыре слоя редакционной работы

**READY — реконструкция по документации, не исходный исполняемый продукт.**

## ORIGINAL
Найдены Техническая документация Copilot.docx и два идентичных файла промптов, SHA в source-manifest.json. Документ описывает Raw → L1 → L2 → L3 → L4 → Body, режимы New/Need Rework, поля rework/comment и флаги Run. Отдельная переработка не должна переписывать исходный AI Draft или чужие слои; результат добавляется в Body с историей. Найдены промпты методолога, редактора/маркетолога, драматурга и финального редактора, выражения $json.raw/inputText/comment/reworkComment. L1 требует поиска по Supabase Vector Store и опоры на Raw при отсутствии подходящих источников.

Экспорт оригинального workflow, подключение Notion, исполняемый backend и оригинальная запись не найдены. Telegram-экспорты переписки из соседних папок не читались и не используются. Документ описывает работу системы, но не доказывает её нынешнюю доступность или все гарантии. Личный вклад Никиты и разрешение на публичный показ требуют подтверждения.

## VERIFIED
Проверены содержание документа и структуры промптов. Для локальной реконструкции: последовательность четырёх стадий, сохранение Body, отдельный rework L3, неизменность всех четырёх Draft, сохранение ручной заметки, история после reload, пустой ввод, граница подготовленного примера, clipboard, modal/Escape и локальный отказ на L2. UI 390/768/1440 без overflow и JS errors. Эти проверки относятся к новому simulator, а не к production n8n.

## PORTFOLIO POLISH / DEMO
Вся показанная web-мастерская — новый presentation layer по найденной спецификации. Она не выдаётся за исторический Notion-интерфейс. Демонстрируется конкретная инженерная идея: несколько независимых ролей, линейная история и переработка одного слоя вместо повторной генерации всего текста.

Один вымышленный редакционный пример; фиксированные ответы и искусственная короткая задержка. Пользовательский произвольный Raw не отправляется модели: демо прямо сообщает, что ответы доступны для встроенного примера. Rework использует фиксированный учебный вариант, не анализирует произвольный комментарий с помощью AI. Дополнительные состояния «В работе / Готово / Ошибка / Переработан», web-панель, localStorage и clipboard — presentation conveniences, не доказанные функции оригинала. Данные вымышленного редактора. Никаких Notion/Supabase/LLM/Telegram-запросов.

## PLANNED / что не проверено
Работа реальной модели, retrieval, качество поиска, production trigger, конкурентные запуски, реальная запись Body/Notion, интеграции и публикация. Промпт L2 шире краткой формулировки документа: содержит маркетинговую роль. Это различие указано, а не скрыто. Метрики экономии времени и клиентские результаты не заявляются.

## Референсы
[Lex](https://lex.page/) — фокус на тексте; [Notion](https://www.notion.com/product/ai) — рабочая страница и свойства; [Jasper](https://www.jasper.ai/) — разделение ролей контент-процесса. Чужие тексты/снимки не копировались.
