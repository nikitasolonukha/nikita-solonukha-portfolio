# PifPaf — master walkthrough

1. Кабинет: профиль, KPI и лучшие ролики.
2. «Мои Reels»: поиск, таблица, сортировка, карточки.
3. Добавление ссылки → получение данных → новый ролик в списке. Это локальный API fixture, не Apify.
4. Карточка ролика → снимки просмотров → обновление → рост.
5. Аналитика → 30 дней / 12 месяцев → графики по периоду.
6. Синхронизация профиля → demo-результат.
7. Профиль → добавление второго профиля → состояние без роликов → возврат к первому.

Отдельный feature clip: недоступный ролик → ошибка → исправление; подтверждение удаления/результат. QA также охватывает login/signup UI и несуществующий результат поиска. Авторизация, Supabase и Apify не проверены живьём; данные вымышлены, обложки — стоковые фотографии, не Instagram-публикации.
