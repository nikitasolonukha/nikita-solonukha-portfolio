# Пифпаф — аналитика Instagram Reels

**READY — портфолио-демонстрация с явно вымышленными данными.**

Кабинет объединяет ролики, историю их показателей и сравнение результатов. Основной сценарий: добавить ссылку, открыть карточку, посмотреть изменение просмотров и сравнить ролики за выбранный период.

Исходники содержат импорт, синхронизацию, аккаунты, карточки, аналитику и авторизацию. Личный объём работы Никиты и разрешение публичного показа ещё требуют подтверждения.

Математика аналитики используется из исходного проекта. Отчёты: master-qa.json, extra-qa.json, master-capture.json; оболочка кейса дополнительно проверена на 320/390/768/1440.

Обложка из настоящего UI; desktop в MacBook, mobile в iPhone. Два master walkthrough показывают кабинет → поиск/таблицу → импорт → карточку → обновление → аналитику → подключение профиля → пустое состояние. Два отдельных feature clips показывают ошибку → повтор → результат → удаление. Запись реального браузера, естественный темп; экспорт 60 fps повторяет кадры, не меняет скорость. Декодированные кадры обоих master просмотрены; все четыре видео и постеры имеют согласованные пропорции без сжатия и чёрных полей.

## PLANNED / ограничения
Живой Instagram, настоящий вход, RLS, сохранение в Supabase и работа Apify не проверены. Скриншоты не подтверждают коммерческий эффект или реальные показатели. Историю первого неполного черновика сохранили в case-history.md; текущий пакет её заменяет.

Справочные источники при проверке границ демо: https://supabase.com/changelog и https://supabase.com/docs/guides/api/securing-your-api . Публичный клиентский UI не считается доказательством защиты данных.

Публичная review-страница проверена на 1440/768/390: четыре видео декодируются, изображения и ссылка на исходный проект работают, overflow и page/HTTP errors нет. **Visual READY для demo-версии.** Показатели и фотографии по-прежнему не выдаются за реальные публикации пользователя; живые Supabase/Apify/Instagram не проверены.
