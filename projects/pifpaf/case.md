# Пифпаф — аналитика Instagram Reels

**READY — локальный пакет, не разрешение на публикацию.**

Кабинет объединяет ролики, историю их показателей и сравнение результатов. Основной сценарий: добавить ссылку, открыть карточку, посмотреть изменение просмотров и сравнить ролики за выбранный период.

## ORIGINAL
Публичный nikitasolonukha/pifpaf-dashboard, commit 055366eba3f2d206a1704c4bc4bcf95c607aa2de. Next.js 16.3.1, React 19.2.8, Tailwind, Recharts, Supabase, Apify. Исходники содержат импорт, синхронизацию, аккаунты, карточки, аналитику и авторизацию. Личный объём работы Никиты и разрешение публичного показа ещё требуют подтверждения.

## VERIFIED
Production-сборка локальной демонстрационной копии выполнена. Исходные node-тесты: 56 PASS, 2 SKIP. Проверены 8 маршрутов на 390/768/1440, поиск, пустой результат, таблица, импорт, ошибка и повтор, удаление, обновление истории, смена периода и подключение второго профиля. Математика аналитики используется из исходного проекта. Отчёты: master-qa.json, extra-qa.json, master-capture.json; оболочка кейса дополнительно проверена на 320/390/768/1440.

## DEMO / MOCK
Отдельная копия work/pifpaf-master; все API направлены только в локальный work/pifpaf-demo-api.mjs. Шесть вымышленных роликов, согласованная история снимков, синтетический профиль Алина Морозова. Данные импорта, задержки, ошибки и синхронизация эмулированы. Фотографии взяты из демонстрационных материалов EP Beauty (их происхождение — в image-sources этого проекта), это иллюстрации, а не публикации реального Instagram-аккаунта. Вход и регистрация — заглушки, не проверка аутентификации. Supabase и Apify не вызываются, внешние аккаунты не изменяются, состояние сбрасывается при перезапуске.

## Материалы
Обложка из настоящего UI; desktop в MacBook, mobile в iPhone. Два master walkthrough показывают кабинет → поиск/таблицу → импорт → карточку → обновление → аналитику → подключение профиля → пустое состояние. Два отдельных feature clips показывают ошибку → повтор → результат → удаление. Запись реального браузера, естественный темп; экспорт 60 fps повторяет кадры, не меняет скорость. Декодированные кадры обоих master просмотрены; все четыре видео и постеры имеют согласованные пропорции без сжатия и чёрных полей.

## PLANNED / ограничения
Живой Instagram, настоящий вход, RLS, сохранение в Supabase и работа Apify не проверены. Скриншоты не подтверждают коммерческий эффект или реальные показатели. Историю первого неполного черновика сохранили в case-history.md; текущий пакет её заменяет.

Справочные источники при проверке границ демо: https://supabase.com/changelog и https://supabase.com/docs/guides/api/securing-your-api . Публичный клиентский UI не считается доказательством защиты данных.
