# Web → Telegram — master walkthrough

| Ориентир | Экран → действие → состояние → результат |
|---|---|
| 00:00–00:04 | Демонстрационная страница заказа → открыть виджет → приветствие → можно задать вопрос |
| 00:04–00:12 | Чат → вопрос о заказе → отправка → сообщение клиента |
| 00:12–00:18 | Ответ через исходный SSE-клиент → сообщение поддержки → понятный результат |
| 00:18–00:23 | Закрыть и снова открыть → сохранённый разговор → контекст не потерян |
| 00:23–00:30 | Второе сообщение → ответ → непрерывная переписка |
| 00:30–00:38 | Перезагрузить страницу → открыть виджет → восстановленная история |

Одинаковые сценарии в desktop и mobile. Скриншоты: страница встраивания, пустой чат, вопрос, ответ, длинная переписка, восстановленная история. Отдельный QA проверяет ошибку отправки/сохранение черновика/retry, дубли, Escape, closed overlay и три ширины. Внешняя сторона Telegram эмулируется локальным адаптером; не показывается как реальная отправка. Исторический UI оператора не найден, поэтому новый operator dashboard не создаётся и не выдаётся за оригинальную функцию.
