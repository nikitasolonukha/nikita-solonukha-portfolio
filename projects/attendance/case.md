# Посещаемость — Telegram, WebApp и API

**Статус: READY (локальный пакет).** Локальная презентационная версия; исходный репозиторий приватный. Публикация исходников и подтверждение личного вклада требуют отдельного ответа.

Приложение собирает отметки о занятиях и рассчитывает посещаемость за месяц. В исходной архитектуре студент взаимодействует с Telegram-ботом, API хранит расписание и отметки через Google Sheets, а WebApp показывает четыре показателя.

Изучены приложения bot, api, webapp и пакеты shared/sheets. В коде присутствуют просмотр занятий, сохранение отметки, месячная статистика, настройка правил, обработчики Telegram и адаптер Google Sheets. Стек: TypeScript, React, Fastify, Telegraf, Google Sheets, Zod.

## VERIFIED

Исходные Fastify handlers выполняются локально, адаптер Google Sheets заменён файловым хранилищем. Проверено: 9/12 = 75%; новая отметка → 10/12 = 83% после округления; перезагрузка сохраняет результат; исправление отметки возвращает 75%. Проверены ошибка загрузки и повтор. Неотмеченные занятия исходный алгоритм считает пропусками; это не изменено для демонстрации.
