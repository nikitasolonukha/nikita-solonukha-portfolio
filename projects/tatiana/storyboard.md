# Татьяна — дополнительный master

Авторские записи остаются в кейсе. Дополнительный walkthrough показывает собранную из найденных исходников локальную версию с небольшими исправлениями доступности.

Главная → мобильное меню → образование и горизонтальная карусель вперёд/назад → три направления с клавиатурными вкладками → формат консультации → контакты/подвал. Внешние сообщения и юридические документы не открываются. Контактный номер скрывается только для записи. Время сцен — master-qa.json.
