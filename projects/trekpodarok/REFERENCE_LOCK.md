# Reference lock — Трек в подарок

## Category

Editorial music gift landing with a Telegram continuation.

## References

- Bandcamp — release-first editorial hierarchy, strong album-object framing, music as culture rather than SaaS.
- Songfinch — the user promise is a one-of-a-kind song built from a personal story.
- Existing product build — vinyl sleeve, warm orange, four occasion tabs and honest Telegram handoff are the product's own visual language.

## Locked direction

Treat the interface as a limited-edition record sleeve: Side A / Side B, restrained black, paper and orange, oversized type and real product frames. Do not introduce dashboards, waveform decoration without audio, testimonial metrics or fake generated tracks.

## Signature interaction

The real product interaction is the four-purpose selector: switching recipient/occasion changes the cover, title, copy and colour as one composition. The vinyl object anchors the hero. The case presents desktop and mobile as two sides of the same release.
