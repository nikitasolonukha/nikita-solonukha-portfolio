# Трек в подарок — master walkthrough

Сценарий реализован в work/trek-capture.cjs. Фактические отметки — capture-report.json. Desktop 1440×900, mobile 390×844.

| Экран | Действие | Состояние / результат |
|---|---|---|
| 00:00 Обложка | Чтение первого экрана | Предложение персональной песни, музыкальная иллюстрация |
| 00:04 Навигация | Вдохновение / мобильное меню | Переход к поводам |
| 00:08 Поводы | День рождения → любимому → друзьям → родителям | Меняются обложка и рекомендации |
| 00:22 Процесс | Скролл | Три этапа исходного Telegram-сценария |
| 00:28 История | Скролл | Пример отправной фразы, не отзыв клиента |
| 00:33 FAQ | Раскрыть вопросы о тексте и цене | Ответы без неподтверждённых обещаний |
| 00:41 Продолжение | CTA | Локальное окно объясняет переход в исходном продукте |
| 00:46 Возврат | Закрыть окно | Возврат на страницу без отправки / заказа |

Mobile показывает меню и адаптивную композицию. Не записываем Telegram, оплату и музыкальную генерацию: эти функции не найдены в этом исходнике.
