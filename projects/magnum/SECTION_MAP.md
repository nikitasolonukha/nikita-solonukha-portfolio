# MAGNUM — Section map

1. **Entrance / full-bleed hero** — one cinematic club image, layered title, date/place line, compact booking action.
2. **People / overlapping photo spread** — two real photographs break the hero boundary; one concise community statement.
3. **Manifesto / type-only score wall** — “не казино / не проденьги / про игру” as a bold editorial pause.
4. **Evening / sticky stage** — active step changes the large image and copy; five stages share one visual field.
5. **Formats / horizontal poster rail** — event formats behave like a season schedule, with image-led panels.
6. **House / full-width location chapter** — building and space imagery with micro captions, no feature cards.
7. **Gallery / asymmetric mosaic** — real club images in varied crops and scales.
8. **Voices / one featured quote + running strip** — social proof as editorial text, not review cards.
9. **Booking / event-poster CTA** — oversized date/action treatment over a real photo.
10. **Location / factual closing band** — address, route and contact in one restrained technical footer.

Composition check: full bleed → overlap → type only → sticky media → horizontal strip → wide media → mosaic → text strip → poster → factual band. One conventional split maximum; no repeated card grid.
