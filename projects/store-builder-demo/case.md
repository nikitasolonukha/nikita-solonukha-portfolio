# Store Builder — от товара к витрине

Статус: READY (локальный пакет). Локальный пакет приватного проекта, не разрешение публикации.

## ORIGINAL
Самостоятельный frontend `ai-shopify-store-builder-demo`, commit 0aa49cfcce0faab9356932e8af39d2db2812cee4. Каталог исходных товаров, загрузка фотографий, валидируемый запрос генерации, AI-провайдер и исходный MockStoreGenerator; главная, каталог, product detail, FAQ, корзина, контактная форма. React/Next, localStorage. Изучены routes, компоненты, схема генерации и обработчик API. Эта версия не подключает Shopify и checkout. Отдельный embedded проект описан в соседнем кейсе, не смешан с прототипом.

## VERIFIED
Сборка Next и TypeScript пройдены. На 390/768/1440 проверены: выбор товара, validation, mock generation, корзина/количество, переходы и reload, FAQ, контактная форма, missing store, загрузка своего фото, ошибка генератора и повтор. ui-qa.json содержит результаты. Проверена именно локальная подготовленная генерация, не качество ответов внешней модели.

## PORTFOLIO POLISH
Корзина сохраняется между маршрутами и перезагрузками. Убрано ложное подтверждение отправки контактной формы. Демо-отзывы и платёжные обозначения помечены. Исправлен fallback описания исходного каталога. Сохранены светлая тема, исходные фотографии и композиция магазина; используется локальная Next-сборка вместо исходного Vinext окружения.

## DEMO / MOCK
PORTFOLIO_DEMO принудительно выбирает исходный mock, не читает API key для внешнего вызова. Контакт Alex Demo, адрес studio.example; сообщения и платежи не отправляются. Отзывы, контент магазина и результаты генерации — демонстрационные. Фотографии из исходного каталога не являются доказательством собственного производства или клиентских прав.

## PLANNED / ограничения
Подключение Shopify/checkout в этой версии не реализовано. LocalStorage не заменяет backend аккаунтов. Нет заявлений о выручке, клиентах или эффективности AI. Личная роль и права публичного показа требуют уточнения в QUESTIONS.md.

## SCREEN → ACTION → STATE → RESULT
Builder → выбрать/загрузить товар → валидация → готовый запрос.
Generating → создать/повторить → progress/error → storefront.
Home/Product → Add to bag → drawer → количество и сумма.
Catalog → открыть товар → detail → FAQ.
Contact → заполнить/отправить → локальное уведомление → отправки нет.

Два master walkthrough, storyboard, screenshots разных состояний и cover показывают настоящий локальный frontend.

Master desktop/mobile просмотрены по декодированным кадрам. Оболочка кейса проверена на 320/390/768/1440: overflow нет, video/poster имеют исходные пропорции и не меняют высоту при запуске.
