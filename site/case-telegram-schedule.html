01 / TELEGRAM SCHEDULE

Одно сообщение.
Сутки публикаций.

Скрипт проходит выбранные папки Telegram, публикует пост и готовит ещё 23 сообщения с часовым интервалом для каждого чата.

1NOWСООБЩЕНИЕ СРАЗУ
→
23SCHEDULEDПО РАСПИСАНИЮ

Результат

Для каждого выбранного чата система отправляет первое сообщение и формирует ещё 23 публикации по расписанию.

Польза

Контент распределяется по чатам автоматически по заранее заданному сценарию.

02 / СЦЕНАРИЙ

Папка. Чат.
Суточная очередь.

01

Исходный пост

Скрипт берёт последнее сообщение из исходного чата.

02

Обход папки

Выбранные Telegram-папки дают список чатов; повтор одного peer_id в рамках запуска пропускается.

03

Отправка и план

Одно сообщение сразу, затем 23 отложенных с шагом в час. Ежедневный старт задавался cron.

05 / РЕЗУЛЬТАТ

Один пост.
План на сутки.

Python/Playwright-сценарий формирует последовательность сообщений для выбранных чатов.

Для каждого чата первое сообщение отправляется сразу, остальные 23 распределяются по расписанию.
