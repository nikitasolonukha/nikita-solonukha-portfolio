TELEGRAM NEWS / TWO PROJECTS

Одна тема.
Две разные работы.

Один проект — готовый университетский бот, другой — личный AI-дайджест в разработке.

Результат

Университетский бот собирает и ищет новости; личная версия развивает сценарий AI-дайджеста.

Польза

Новости из нескольких источников можно собирать и находить через Telegram.

VERSION 01 / PERSONAL / DEVELOPMENT

AI News Digest

Историческая карточка описывает сбор публикаций, отбор под интересы и AI-суммаризацию. Проект был отмечен как находящийся в разработке.

TELETHON → FILTER → SUMMARY → PROFILE → DIGEST
Личная версия развивает сценарий тематического AI-дайджеста.
VERSION 02 / UNIVERSITY / IMPLEMENTED

Telegram Parser / Search

Отдельный университетский репозиторий parser-tg-muiv: Telegram-бот, Telethon-сбор, SQLite и поиск по сохранённым сообщениям.

CHANNELS → PARSER → SQLITE → SEARCH → BOT
Университетский бот собирает публикации и позволяет искать по сохранённым сообщениям.
PROJECT RELATION

Общая тема.
Разный статус.
